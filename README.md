## 📅 Monthly Update Steps

At the end of each month, Claude builds you a new `index.html` with the updated data.  
To publish it, follow these steps on **github.com** — no downloads or command line needed.

1. Go to your repository on github.com
2. Click on **`index.html`** in the file list
3. Click the **pencil icon** (Edit) in the top right of the file view
4. Click **"..."** → **"Upload file"** (or look for the upload option near the edit button)  
   *(alternatively: delete the old file first, then use "Add file → Upload files")*
5. Drag the new `index.html` onto the upload area, or click to browse for it
6. Scroll down and click **"Commit changes"**
7. Wait about 60 seconds, then refresh your Pages URL — done ✅

> **Tip:** GitHub Pages can take up to 2 minutes to reflect changes after committing.  
> Hard-refresh the page (Ctrl+Shift+R on desktop, or clear Safari cache on iPhone) if you don't see the update immediately.

## 🗓️ Year-End Transition (Dec → Jan)

When starting 2027:
1. Create a **new GitHub repository** (e.g. `mpvfd-2027`)
2. Enable GitHub Pages on it
3. Upload the first month's `index.html` for 2027
4. Share the new URL with department members
5. The 2026 repo and URL stay live as a permanent archive — no action needed
